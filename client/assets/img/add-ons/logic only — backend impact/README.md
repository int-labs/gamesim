# Logic-Only Backend Impact Icons

This folder contains pixel-art icon assets for add-ons that do **not** appear physically on top of the notebook.

These assets are used as **UI indicators** to communicate the business effect of selected add-ons or upgrades.

## Purpose

These icons represent backend simulation impacts such as:

- Premium positioning
- Cost reduction
- Production speed improvement
- Demand boost
- Quality improvement
- Margin improvement

## Usage Rules

- Use these as small UI badges, effect indicators, or tooltip icons.
- Do not place these directly on the notebook canvas as physical objects.
- Do not stack these above the notebook.
- Do not treat them as writing tools or decorative add-ons.
- They should appear in sidebars, cards, dashboards, tooltips, or result summaries.

## Visual Style

- Pixel-art icon style
- Chroma key green background for masking: `#00FF00`
- Centered object
- No text
- No notebook
- No UI frame
- Clear symbolic meaning
- Consistent badge/token style

## Current Icons

- `premium_upgrade`

- `production_speed_upgrade`
- `demand_boost_pack`

## Simulation Meaning

These icons help users understand how their decisions affect the simulation model, especially:

- P&L
- Cost structure
- Production efficiency
- Customer demand
- Product positioning
- Business performance

They are visual feedback for decision consequences, not physical product parts.
